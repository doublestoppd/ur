CPSI Utilization Review Data Compiler

Offline compilation of CPSI/Evident encounter exports into utilization-review metrics, objective review queues, and an Excel workbook.

Runs offline · no network calls

Patient data stays in this browser tab's memory for this run only. It is never written to browser storage and never leaves this workstation. Only reference mappings and thresholds are saved locally.

Select or drop one or more CPSI Ad Hoc exports (.xlsx, .xls, or .csv). Multiple months may be imported together.

2. Map fields

Known CPSI field names are mapped automatically. Where two source columns are equally plausible, the tool does not choose — select the correct column below. Sample values are shown from the loaded file and are never saved.

3. Rules & reference codes

Reference mappings and operational thresholds are editable here. Core calculation formulas are not editable in the interface; they are centralized in the calculation rule registry and documented in the Calculation Reference.

5. Results

Accounts

Every account that was imported, including the ones excluded from the metrics. Select one to see the complete patient course: each source cell exactly as it arrived beside the value the tool derived from it, every status transition it accepted or refused, and every judgement it made. This view exists so the interpretation can be checked against the chart, account by account.

Graphs

Every graph is drawn from the same calculated metrics as the results and the workbook, and names the Rule IDs behind it. Each one can be saved as a PNG on a light background, sized to drop into a document. Hover a graph for values, or open its data table.

6. Export workbook

Calculation Reference

Generated from the same rule registry the calculation engine uses. Every metric and review trigger below is exported with the workbook. Read-only: changing a formula requires a source-code change, a rule-version increment, and updated unit tests.

External references

This utility performs objective data processing only. It does not make InterQual determinations, avoidable-day decisions, Code 44 decisions, denial or medical-necessity conclusions, and it cannot verify that an IMM or MOON was delivered or signed. Regulatory calculations are surveillance aids and must be validated against hospital policy and current payer/CMS requirements before being treated as official compliance reporting.

Spreadsheet engine: SheetJS Community Edition (Apache 2.0), bundled locally in vendor/. No content is loaded from the internet.
