CPSI Utilization Review Data Compiler

Offline compilation of CPSI/Evident encounter exports into utilization-review metrics, objective review queues, and an Excel workbook.

Runs offline · no network calls

Patient data stays in this browser tab's memory for this run only. It is never written to browser storage and never leaves this workstation. Only reference mappings and thresholds are saved locally.

External references

This utility performs objective data processing only. It does not make InterQual determinations, avoidable-day decisions, Code 44 decisions, denial or medical-necessity conclusions, and it cannot verify that an IMM or MOON was delivered or signed. Regulatory calculations are surveillance aids and must be validated against hospital policy and current payer/CMS requirements before being treated as official compliance reporting.

Spreadsheet engine: SheetJS Community Edition (Apache 2.0), bundled locally in vendor/. No content is loaded from the internet.
