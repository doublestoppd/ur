CPSI Utilization Review Data Compiler

Offline compilation of CPSI/Evident encounter exports into utilization-review metrics, objective review queues, and an Excel workbook.

Runs offline · no network calls

Patient data stays in this tab's memory for this run only — never in browser storage, never off this workstation. Only mappings and thresholds are saved.

Import

Add every document for the period you are compiling, then press Process & review. Nothing is processed until you do, so files can be added in any order. Three kinds of file are understood:

  • CPSI Ad Hoc export (.xlsx / .xls / .csv) — the patient data. Expected columns: ipv1_num (account), visit_name, ipv1_age_years, visit_servicecd_key, ipv1_ad_date / ipv1_ad_time, ipv1_dis_date / ipv1_dis_time, visit_ins, ipv1_discd, ipv1_origin. Several files combine into one run (for example, the reporting month plus the prior 30 days for readmission history).
  • CPSI Service Log report (.pdf, report CNSERVLOG — Service Log for Service CD, Changed From: OS / Changed To: IP) — optional. Each OS → IP change becomes an observation segment on the matching inpatient account automatically.
  • A workbook this tool exported (.xlsx) — restores that session exactly as it was; more files can then be added on top.

Reference mappings and thresholds, editable. Calculation formulas are not editable here — they live in the rule registry, documented in the Calculation Reference.

Overview

Reporting period

Pick a preset or set exact dates above. A stay that only partly overlaps the chosen period still counts in patient, review, occupancy, and discharged-stay figures; only the admission event itself must fall inside the period to count as an admission.

Metrics

Review queue

Accounts that met an objective trigger, one row per account with every reason attached. Select a row to open the full patient course. No row expresses a clinical, medical-necessity, denial, or compliance conclusion.

Accounts

Every imported account, including the excluded ones. Select one to see the whole patient course — each source cell beside the value the tool derived from it — so the interpretation can be checked against the chart.

Graphs

Drawn from the same metrics as the workbook, each labelled with its Rule IDs. Hover for values; every graph exports to PNG.

Export workbook

Calculation Reference

Generated from the same rule registry the calculation engine uses. Every metric and review trigger below is exported with the workbook. Read-only: changing a formula requires a source-code change, a rule-version increment, and updated unit tests.

External references

This utility performs objective data processing only. It does not make InterQual determinations, avoidable-day decisions, Code 44 decisions, denial or medical-necessity conclusions. Regulatory calculations are surveillance aids and must be validated against hospital policy and current payer/CMS requirements before being treated as official compliance reporting.

Spreadsheet engine: SheetJS Community Edition (Apache 2.0), bundled locally in vendor/. No content is loaded from the internet.
